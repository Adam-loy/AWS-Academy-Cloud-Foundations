# AWS-Academy-Cloud-Foundations
AWS Academy Cloud Foundations is intended for students who seek an overall understanding of cloud computing concepts, independent of specific technical roles. It provides a detailed overview of cloud concepts, AWS core services, security, architecture, pricing, and support.

Personal study notes and learning journal for **AWS Academy / AWS Cloud Foundations**.

This repository contains my own notes, explanations, examples, commands, diagrams, and practical observations that I create while studying AWS Cloud Foundations.

## About This Repository

I created this repository to document my learning journey while studying AWS Cloud Foundations and preparing for AWS-related certification.

My goal is to make my **personal understanding and notes** available in two convenient formats:

- **GitHub:** Markdown files organized by lesson/topic.
- **Blog:** A more readable, article-style version of the same learning notes on my blog:
  https://clou-computing.blogspot.com/

The blog version is intended to feel like reading a structured study document, while the GitHub repository provides the same knowledge in a version-controlled and easily searchable format.

## Why Am I Sharing My Notes?

Cloud computing and certification preparation can be difficult to approach when you have limited financial resources or cannot find explanations that match your learning style.

I am fortunate to have access to AWS training, and I want to share what **I personally learn and understand** so that other students can benefit from additional explanations and learning references.

These notes are especially intended for students and learners who want to understand AWS concepts but may not have access to the same learning opportunities.

## Important Note About My Course Access
